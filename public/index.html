Zugang einrichten

Die Verfügbarkeitsdaten kommen live von TMDB (Daten von JustWatch). Du brauchst einen kostenlosen Schlüssel:

  1. Konto auf themoviedb.org anlegen
  2. Unter Einstellungen → API einen Schlüssel beantragen
  3. „API-Schlüssel“ oder „Lesezugriffstoken“ hier einfügen

Mit eigenem Cloudflare-Worker trägst du seine Adresse in config.js ein, dann entfällt dieser Schritt auf allen Geräten.

Sicherungen

Der Worker sichert deine Daten jede Woche automatisch und hebt die letzten zehn Stände auf. Beim Zurückholen werden sie mit deinem aktuellen Stand zusammengeführt, es geht nichts verloren.

Trakt

Kino
